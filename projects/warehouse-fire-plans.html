Warehouse Fire Escape Plans

Project Example

Updated warehouse floor plans using on-site measurements and developed nine fire escape drawings to identify nearby exits throughout the facility.

Project Overview

Existing warehouse floor plans did not reflect all of the offices and other structures added since the original drawings were created. I was responsible for identifying these changes on-site, updating the layouts in AutoCAD, and preparing fire escape plans for use throughout the warehouse.

Contributions

  • Visited the warehouse to measure offices and other structures that were missing from the existing floor plans.
  • Incorporated the measured dimensions and layout changes into the existing AutoCAD drawings.
  • Prepared nine fire escape plans showing the nearest fire exit from different areas of the warehouse.

Technical Approach

The project began with existing floor plans, which served as the base for the updates. I compared the drawings with the physical warehouse, measured newly constructed areas, and revised the AutoCAD layouts to reflect the current conditions.

Using the updated layouts, I created nine evacuation drawings to help occupants identify the closest fire exit from different locations within the warehouse.

Application

The updated drawings provided a more current representation of the warehouse layout and supported facility emergency planning. The nine plans were intended to make nearby exit routes easier to identify across different areas of the facility.

Summary

  • On-site dimensional measurement
  • Existing-layout verification and revision
  • AutoCAD drafting and facility layouts
  • Technical documentation and safety planning
